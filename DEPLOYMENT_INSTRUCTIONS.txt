================================================================================
                    OPSPILOT - QUICK DEPLOYMENT & SYNC CHEATSHEET
================================================================================

For the complete, detailed deployment manual and upstream sync guide, see:
   DEPLOYMENT_GUIDE.md

--------------------------------------------------------------------------------
1. FIRST-TIME DEPLOYMENT ON A NEW SERVER:
--------------------------------------------------------------------------------

   # Clone repository & checkout branch
   git clone https://github.com/pran786/Opspilot.git
   cd Opspilot
   git checkout feature/custom-theme

   # Build & start containers (Fast mode)
   docker compose -f docker-compose-fast.yml up -d --build

   # Run DB migration & initialize admin user
   docker compose -f docker-compose-fast.yml exec superset superset db upgrade
   docker compose -f docker-compose-fast.yml exec superset superset fab create-admin --username admin --firstname Superset --lastname Admin --email admin@opspilot.com --password admin
   docker compose -f docker-compose-fast.yml exec superset superset init

   # Seed all 4 OpsPilot Big-Screen TV Dashboards
   docker compose -f docker-compose-fast.yml exec superset python scripts/seed_all_opspilot_dashboards.py

   # Access application:
   - Web App (Nginx Port 80):    http://<SERVER_IP>/opspilot/welcome/
   - Direct Port 8088:           http://<SERVER_IP>:8088/opspilot/welcome/
   - Login:                      admin / admin

--------------------------------------------------------------------------------
2. PULLING LATEST OPSPILOT UPDATES (ON SERVER):
--------------------------------------------------------------------------------

   cd Opspilot
   git pull origin feature/custom-theme
   docker compose -f docker-compose-fast.yml up -d --build
   docker compose -f docker-compose-fast.yml exec superset superset db upgrade
   docker compose -f docker-compose-fast.yml exec superset python scripts/seed_all_opspilot_dashboards.py

--------------------------------------------------------------------------------
3. SYNCING WITH UPSTREAM APACHE SUPERSET (CODEBASE MAINTENANCE):
--------------------------------------------------------------------------------

   # One-time upstream setup:
   git remote add upstream https://github.com/apache/superset.git

   # Sync workflow:
   git fetch upstream master
   git checkout feature/custom-theme
   git checkout -b sync/upstream-sync
   git merge upstream/master

   # (Resolve conflicts if any, preserving custom plugins in superset-frontend/plugins/
   # and custom scripts in scripts/)

   # Build and verify containers:
   docker compose -f docker-compose-fast.yml up -d --build

   # Merge to custom-theme and push:
   git checkout feature/custom-theme
   git merge sync/upstream-sync
   git push origin feature/custom-theme

--------------------------------------------------------------------------------
4. USEFUL OPS COMMANDS:
--------------------------------------------------------------------------------
   - View container status:    docker compose -f docker-compose-fast.yml ps
   - View live logs:           docker compose -f docker-compose-fast.yml logs -f
   - Restart superset:         docker compose -f docker-compose-fast.yml restart superset
   - Reset admin password:     docker compose -f docker-compose-fast.yml exec superset superset fab reset-password --username admin --password admin
   - Stop services:            docker compose -f docker-compose-fast.yml down
